# IA aplicada a la empresa · 2.º DAM

Página del curso de **Inteligencia Artificial Aplicada a la Empresa** (IES Donoso Cortés, curso 2026-2027).

Web publicada con GitHub Pages: abre `index.html` (portada) y, desde ahí, la página de cada unidad.

## Estructura

| Ruta | Qué es |
|---|---|
| `index.html` | Portada: ciclo de reto, las 11 unidades, empresas del curso y reglas |
| `ud1.html`, `ud2.html`, `ud3.html` | Una página por unidad |
| `assets/site.css` | Estilos comunes |
| `descargas/` | Material descargable (guías, cuadernos) |

Todo es HTML estático, sin compilación. Los datos de las empresas son ficticios.
